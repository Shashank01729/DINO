# Chrome Dinosaur Game (Custom Version)

A fun browser-based dinosaur game inspired by the classic Chrome offline game. This version includes extra features like flying and cactus-cutting power-ups!

## 🕹️ How to Play

- Press `Space` to **Start** the game.
- Press `Space` or `Arrow Up` to **Jump**.
- Avoid the **Cactus** by jumping or using special powers.

### Power-Up Instructions (Available when Score ≥ 5):

- Press `F` to **Fly** for 10 seconds (Costs 5 points).
- Press `G` to **Cut the Cactus** (Removes it instantly, Costs 5 points).

### Game Over

- If the dinosaur collides with the cactus:
  - Press `Enter` to **Restart** the game.
  - Or press `Space` to reset and begin again.
